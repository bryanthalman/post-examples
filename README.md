# Post – Secure File Transfer & Automation

**A modern alternative to traditional FTP and SFTP workflows.**

Post is a secure, zero-knowledge encrypted file and message transfer application developed by **Utah Software, LLC**.

Designed for developers, system administrators, businesses, and automation workflows, Post provides a command-line interface (CLI) for transferring files securely without maintaining traditional FTP or SFTP server infrastructure.

## Why Post?

Traditional FTP and SFTP workflows often involve server administration, user accounts, SSH keys, firewall configuration, and custom automation scripts.

Post offers a different approach: secure file and message transfers through an encrypted relay service and a scriptable command-line client.

### Key Features

- **Secure File Transfer** – Transfer files using zero-knowledge encryption.
- **FTP/SFTP Alternative** – A modern file transfer workflow without operating a traditional FTP or SFTP server.
- **Command-Line Interface** – Designed for terminal users, developers, and administrators.
- **Automation Friendly** – Suitable for integration into scripts and automated workflows.
- **AI-Friendly Development** – A CLI that can be used in AI-assisted development and automation workflows.
- **Cross-Platform** – Available for Windows and Linux.
- **Flexible Pricing** – Free and paid plans for individuals and businesses.

## Post vs. FTP and SFTP

Post is an alternative approach to secure file transfer, not a drop-in implementation of the FTP or SFTP protocols.

It is intended for workflows where an encrypted relay service and command-line automation are preferable to maintaining a traditional file transfer server.

Existing systems that specifically require an FTP or SFTP protocol endpoint may still need those protocols.
